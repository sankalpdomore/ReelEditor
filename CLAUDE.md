# CLAUDE.md: Reel Editor for Mac

## What this is

Reel Editor for Mac is Sankalp's native Mac video editor for his talking head and job lead reels (SwiftUI and AVFoundation), with an MCP server inside it, `reel-mcp`, so Claude or any agent edits the same projects through tools. It began as `tools/reel-editor-mac` inside the ContentApp repo and was detached into this repo on 1 Nov 2026; the copy in ContentApp is frozen as it was that day, so every change happens here. `README.md` explains how the app works in detail, and `WIP-README-Reel-Editor-Mac-App.md` is the PRD with the checklist of what is done and what is open.

## Build, run and test

- `./build.sh` builds in release mode, signs, installs to `~/Applications/Reel Editor.app` and opens it; `./build.sh --no-open` skips opening. Quit the running app first (`osascript -e 'quit app "Reel Editor"'`).
- `swift build` builds debug binaries in `.build/debug` for quick checks.
- `python3 tests/mcp_test.py .build/debug/reel-mcp <scratch folder>` runs the MCP suite (590 checks) against a fresh projects folder in the scratch folder, with the media in `tests/media`. Run it after any change to `Sources/ReelCore` or `Sources/ReelMCP`, and add checks for new tools.
- After a visual change, check it in a window snapshot: `REEL_EDITOR_SNAPSHOT=<file.png> .build/debug/ReelEditor` writes the window every few seconds and keeps the app in the background so it never takes the keyboard. `REEL_EDITOR_FLOAT` (captions and voice too), `REEL_EDITOR_SEEK`, `REEL_EDITOR_APP_SETTINGS`, `REEL_EDITOR_SELECT`, `REEL_EDITOR_MCP`, `REEL_EDITOR_OPEN_MENU`, `REEL_EDITOR_DIRECT_SAY` and `REEL_EDITOR_RULES` open a state at launch (README, Look). Report what was seen, and name what a snapshot cannot show (drags, pinch, motion) for Sankalp to try.
- Never point tests or snapshots at Sankalp's real projects: set `REEL_EDITOR_HOME` to a scratch folder. His projects are on the list in `~/Movies/Reel Editor/projects.json`, each one a `<name>.reel.json` file that may be saved anywhere.

## Design rules

The app uses the ContentApp web app's design language, not stock macOS (Sankalp, 31 Oct 2026), ported in `Sources/ReelEditor/Design.swift`. Read and follow `/Users/sankalpsinha/Coding projects/NextDoorCompanyCode/DESIGN.md` for any interface work, applied here as:

- Reuse the components in `Design.swift` (pills, `SegmentTabs`, `InsetCard`, `Field`, `ValueSlider`, `Dropdown`, `CardChrome` and the rest) before writing a new one, and add a variant there rather than restyling at the call site.
- Spacing in multiples of 4, Inter at 14 by default, the grey stops #111 to #eee from `Ink`, every resting border #ddd, each nested box 4 points less rounded than the one around it.
- Icons are Phosphor only: `Icon("name")` as the web's `ph-bold ph-name`; run `./phosphor-codes.sh` after naming a new icon. No SF Symbols in the interface, except inside the system's own right click menus.
- Cards, menus and panels open inside the window, right aligned to what opened them, spring open and closed with `Animation.cardOpen` and `.cardClose`, and cast their shadow on their shape only.
- Red is kept for cuts on the timeline.
